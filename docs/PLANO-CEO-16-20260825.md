## Decisões travadas

1. **Posição** = número `1..N` (capacidade da mesa). Sem mapa visual.
2. **10%** = taxa de serviço sugerida no fechamento (base = subtotal itens). Removível no fechamento. Não é % Tech42.
3. **Mesa libera** só com saldo zero (todas cobranças quitadas) + ação explícita liberar/fechar.
4. **Transferência v1:** cliente solicita posição destino → pendente → garçom confirma com a pessoa → aprova/nega.
5. **Papéis:** `admin` (dono) e `garçom`. Admin faz tudo; garçom solicita cancel/estorno/edit.
6. **Tema:** default = `prefers-color-scheme`; override opcional (`system` / `light` / `dark`).
7. **Paleta:** sem marrom/madeira; tokens design v3 (ardósia `#0F1419` + âmbar `#FFC233`).
8. **Pagamento:** continua manual/demo neste ciclo.
9. **PRs:** preferir 1 PR por fase (não misturar tema + schema + RBAC + dashboard).
